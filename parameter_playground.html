Adjust model parameters live, see outcomes update, export your scenario as a CSV

Modified

May 12, 2026

TipHow to use this page
  1. Adjust any of the model parameters using the sliders / inputs below. The headline outcomes (deaths averted, burden avoided, net monetary benefit, ROI) update live in your browser — nothing is sent to any server.
  2. Export your scenario by clicking Download my scenario CSV. Save the file with a meaningful name (e.g. scenario_low_eta.csv).
  3. Reload later by clicking Import a saved scenario and selecting your saved CSV — the inputs will repopulate from the file.
  4. Reset at any time using the Reset to canonical v3 button.

The starting values are loaded from the canonical amua_import_parameters_v3.csv. For provenance and source citations on every parameter, see the Parameters Hub.

Code 
csvText = FileAttachment("amua_import_parameters_v3.csv").text()

canonical = {
  const lines = csvText.split("\n").filter(l => l && !l.startsWith("#") && !l.startsWith("Name,"));
  const out = {};
  for (const line of lines) {
    const m = line.match(/^([^,]+),([^,]+),(.*)$/);
    if (!m) continue;
    const [, name, expr, notes] = m;
    const v = parseFloat(expr);
    if (!isNaN(v)) out[name.trim()] = { value: v, notes };
  }
  return out;
}

  if (importFile) {
    const text = await importFile.text();
    const lines = text.split("\n").filter(l => l && !l.startsWith("#") && !l.startsWith("Name,"));
    const obj = {};

      const m = line.match(/^([^,]+),([^,]+),(.*)$/);

    return html`<div class="alert alert-success" style="padding:8px;background:#cfc;border-left:4px solid #060;margin:8px 0;">
      ✓ Imported ${Object.keys(obj).length} parameters. Adjust below or export again.
    </div>`;
  }
  return html``;

C_morbidity         = n_burden_true * c_morbidity_headline
C_mortality         = n_deaths * c_mortality_human_capital
C_burden_total      = C_morbidity + C_mortality

// Detection × efficacy
deaths_averted      = n_deaths * (d_full_package - d_status_quo) * eta_response_mid
cases_averted       = n_burden_true * (d_full_package - d_status_quo) * eta_response_mid
burden_avoided      = C_burden_total * (d_full_package - d_status_quo) * eta_response_mid

// NMB and ROI
NMB_narrow          = burden_avoided - c_full_package_narrow_operating
NMB_wholesystem     = burden_avoided - c_full_package_wholesystem_operating
ROI_narrow          = burden_avoided / c_full_package_narrow_operating
ROI_wholesystem     = burden_avoided / c_full_package_wholesystem_operating

// ---------- Stakeholder split of avoided burden ----------
// Apply the canonical share table (NDoH ~R70M, NHLS ~R10M, OOP ~R10M,
// household mortality ~R2.25B of the R2.34B headline burden) proportionally
// to whatever total burden the user has built with the sliders.

share_nhls_frac    = 10e6  / 2340e6   // ~0.4%
share_oop_frac     = 10e6  / 2340e6   // ~0.4%
share_hh_mort_frac = 2250e6 / 2340e6  // ~96.2%

avoided_nhls       = burden_avoided * share_nhls_frac
avoided_oop        = burden_avoided * share_oop_frac
avoided_hh_mort    = burden_avoided * share_hh_mort_frac

avoided_household  = avoided_oop + avoided_hh_mort

}

exportCSV = {
  const header = "Name,Expression,Notes\n";
  const note = (k) => canonical[k]?.notes ?? "User-edited via Parameter Playground";
  const rows = editedKeys.map(([k, v]) => `${k},${v},${note(k)}`).join("\n");
  const timestamp = new Date().toISOString().split(".")[0];
  return header
    + `# Scenario exported from Parameter Playground at ${timestamp},,\n`
    + `# Canonical baseline: amua_import_parameters_v3.csv,,\n`
    + rows + "\n";
}

downloadLink = {
  const blob = new Blob([exportCSV], {type: "text/csv"});
  const url = URL.createObjectURL(blob);
  return html`<a href="${url}" download="d2p_scenario_${new Date().toISOString().split("T")[0]}.csv"
                 style="display:inline-block;padding:10px 18px;background:#04a;color:white;
                        text-decoration:none;border-radius:4px;font-weight:bold;margin:8px 4px;">
    ⬇ Download my scenario CSV
  </a>`;
}

NoteHow does this differ from the Parameters Hub?
  • Parameters Hub is the read-only canonical record of every parameter with sources. It always reflects the committed amua_import_parameters_v3.csv.
  • Parameter Playground (this page) is a what-if sandbox. Edits live only in your browser session, never touch the canonical file, and can be exported / re-imported as CSVs for sharing with colleagues.

To make a scenario canonical, share the exported CSV with the project maintainer for review and incorporation into amua_import_parameters_v3.csv via a tracked commit.

## How to use this page

1. **Adjust** any of the model parameters using the sliders / inputs below. The headline outcomes (deaths averted, burden avoided, net monetary benefit, ROI) update **live in your browser** — nothing is sent to any server.
2. **Export** your scenario by clicking *Download my scenario CSV*. Save the file with a meaningful name (e.g. `scenario_low_eta.csv`).
3. **Reload later** by clicking *Import a saved scenario* and selecting your saved CSV — the inputs will repopulate from the file.
4. **Reset** at any time using the *Reset to canonical v3* button.

The starting values are loaded from the canonical [`amua_import_parameters_v3.csv`](amua_import_parameters_v3.csv). For provenance and source citations on every parameter, see the [Parameters Hub](parameters_hub.html).

//| echo: false

// Build a CSV that mirrors the canonical structure for the edited parameters
exportCSV = {
  const header = "Name,Expression,Notes\n";
  const note = (k) => canonical[k]?.notes ?? "User-edited via Parameter Playground";
  const rows = editedKeys.map(([k, v]) => `${k},${v},${note(k)}`).join("\n");
  const timestamp = new Date().toISOString().split(".")[0];
  return header
    + `# Scenario exported from Parameter Playground at ${timestamp},,\n`
    + `# Canonical baseline: amua_import_parameters_v3.csv,,\n`
    + rows + "\n";
}

::: {.callout-note icon=false}
## How does this differ from the [Parameters Hub](parameters_hub.html)?

- **Parameters Hub** is the **read-only canonical record** of every parameter with sources. It always reflects the committed `amua_import_parameters_v3.csv`.
- **Parameter Playground** (this page) is a **what-if sandbox**. Edits live only in your browser session, never touch the canonical file, and can be exported / re-imported as CSVs for sharing with colleagues.

To make a scenario *canonical*, share the exported CSV with the project maintainer for review and incorporation into `amua_import_parameters_v3.csv` via a tracked commit.
